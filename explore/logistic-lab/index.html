Reading itEach column is one r: the long-run values of x. One line = fixed point, two = 2-cycle. Colour = detected period, white = no period found.
Lyapunov exponent λAverage of ln|r(1 − 2x)| along the orbit. Below 0 (teal) nearby orbits converge; above 0 (red) they separate: chaos. It touches 0 at every doubling.
Use itDrag a box to zoom. Tap to set r. Inside the chaos, look for the white stripes that turn into colour: periodic windows, each with its own doubling cascade.

Feigenbaum table

rₙ: the 2ⁿ⁻¹-cycle loses stability (multiplier −1) and the 2ⁿ-cycle is born. Rₙ: the 2ⁿ-cycle is superstable (it contains x = ½). Both are solved here by Newton's method, live. Amber digits agree with δ = 4.669201609… and α = 2.502907875….

δ = ratio of successive gaps in r. α = ratio of successive distances dₙ = f^(2ⁿ⁻¹)(½) − ½ at Rₙ, with alternating sign. Both are universal: every smooth one-hump map gives the same numbers.

Basins on the line

Map aboveHorizontal r, vertical starting point x₀. Each pixel is coloured by which point of the attracting cycle its orbit lines up with (its phase), brighter = faster. Grey = chaotic attractor, dark red bands = escape to −∞ (x₀ outside [0, 1]).
Strip at current rBasins of the p cycle points under fᵖ. Triangles: attracting points. Rings: repelling periodic points. Basin edges sit on repellers and their preimages.
Why one attractorThe logistic map has negative Schwarzian derivative, so it has at most one attracting cycle and x = ½ always falls into it (Singer). On the line the basins differ only in phase.

The same map with complex z at the current r. Coloured: the basin of each cycle point (filled Julia set). Dark blue: escape to ∞. The edge is the Julia set; at r = 4 it shrinks to [0, 1].

Parameter plane: complex r

Tap anywhere to read the period at a complex r. Taps near the real axis also set r.

Each r coloured by the period of its attracting cycle. This is the Mandelbrot set in disguise: c = r/2 − r²/4. The real segment 1 ≤ r ≤ 4 is its spine from c = ¼ to c = −2; every bulb is a periodic window.
