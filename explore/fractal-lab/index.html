Choose the universe, how it is measured, and how far the camera may go. Every fractal then uses the same camera, capture and information tools.

1 · Fractal library

The seed c is fixed; every pixel is a starting point z₀. In a Mandelbrot simulation you can also pin a point and open its Julia set from ⓘ.
Power n in z → zⁿ + c. The set has n − 1 fold symmetry.
Zeta Map and Snowflake Group are different kinds of engine (a phase map and a geometric curve) and keep their own viewers.

3 · Maximum zoom depth

Depth D = log₂(W₀ / W): each level halves the visible width. A limit stops zooming in only; panning and zooming out stay free.

4 · Colour scheme

Colour is applied after the computation, so switching scheme never changes the numbers.

5 · Numerics

Iteration limit
Escape radius
Auto raises the limit with depth, as the Mandelbrot Map does. Radius 2 is the textbook threshold; 16 gives a smoother μ and the look of the existing maps.
