M24 Viewer

244,823,040 ways to shuffle 24 points that keep the Golay code intact. Four moves make all of them. Count what each one leaves in place, and the counts build the character table.

1A1²⁴

Four moves

The points are ∞ and the numbers 0 to 22, counted mod 23. Each tap multiplies the current symmetry g by one move. α, β and γ are fractional maps x ↦ (ax+b)/(cx+d); together they make PSL(2, 23), only 6,072 symmetries. δ is Conway's move: cube x, then divide by 9 if x is a nonzero square mod 23, multiply by 9 if it isn't. Add δ and the four moves make every one of the 244,823,040.

Count what stays put

Seven kinds of object live on the 24 points. Each count below is how many of them g sends to themselves. Tap a row to see one on the board, tap again for the next, then press Play: the colours travel and land back in the same pattern.

Every element of a class gives the same seven counts, so a count is a function on the 26 classes. Functions like this are characters.

26 classes

Elements that are the same move seen from a different start form a conjugacy class. Tap one to load a random member. The census draws random symmetries and sorts them; each class should turn up in proportion 1/|C(g)|.

Build the character table

Each count row is a character. Peel strips off every irreducible you already know; when what remains has norm ⟨χ, χ⟩ = 1, it is a new irreducible. Start with Fixed points → Peel. Later, multiply characters you have found (×, ∧², S²) and peel the result.

The table

Rows you have found are dark; the rest stay faint until you find them. The current class is shaded. Tap a cell for its exact value.

Counting only ever produces whole numbers, so it reaches the 16 rational characters and the five complex pairs only as sums (45a+45b, 231a+231b, 770a+770b, 990a+990b, 1035b+1035c). Splitting a pair takes √−7, √−15 or √−23: the same information that tells 7A from 7B, 15A from 15B and 23A from 23B, and no count can see it. The Golay code over 𝔽₂ can, which is how this page names those classes.
