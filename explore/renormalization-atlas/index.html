How the machine works

First find the parameter at which the critical point returns after 1, 2, 4, 8, … iterations. Extrapolate their limiting parameter. At that parameter, let q be the critical point and sₖ = f²ᵏ(q) − q, where the exponent denotes iteration. Plot gₖ(x) = [f²ᵏ(q + sₖx) − q]/sₖ. This forces gₖ(0)=1 but does not force the rest of the curve to match.

Compare αₖ = sₖ/sₖ₊₁ and δₖ = (pₖ₋₁ − pₖ₋₂)/(pₖ − pₖ₋₁). Depth is capped at 7 to keep finite-precision errors small. The reference curve, if selected, is a numerical return map at depth 7, not an exact fixed point.
